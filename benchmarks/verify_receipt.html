Independent LIN Compute-Receipt Verifier

Zero-trust: this page verifies a LIN receipt without the LIN compiler, using only the browser's native WebCrypto SHA-256 (NIST FIPS 180-4). Nothing is uploaded — everything runs locally. Accepts the JSON export or the native RULEL format.

Open format: merkle_root = SHA-256( SHA-256(source) ‖ output‖LE ‖ steps‖LE ‖ sp_at_ret‖LE ‖ input‖LE ) 

Paste a receipt (JSON or RULEL) and click "Verify receipt".
